# timirkuntala
তিমিরকুন্তলা - A comprehensive Bengali social media platform with posts, messaging, shopping, games, and professional settings

## New Feature: Albums

Open `albums.html` to use the albums section.

### Features implemented:

1. **Permanent Media Storage**
   - Every photo/video uploaded to an album stays permanently.
   - Media is only removed when the user explicitly deletes it.
   - No auto-cleanup or temporary storage.

2. **Album Cover Photo Selection**
   - Choose a cover image when creating or editing an album.
   - Preview the cover before saving.
   - Change or remove cover later.

3. **Other**
   - Create unlimited albums
   - Privacy options (Public / Friends / Only Me)
   - Upload multiple images & videos
   - Mobile-friendly UI matching the original design
   - Data stored in browser localStorage (demo)

### How to use
1. Open `albums.html` in a browser
2. Tap **Create Album**
3. Enter name, choose privacy, select cover photo
4. Upload media – it will stay until you delete it
